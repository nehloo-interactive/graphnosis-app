# scripts/disclosure-held.txt — the files that MUST NOT become tracked.
#
# The counterpart to scripts/tests-allowlist.txt, and deliberately a SEPARATE
# file for the same reason that one is separate from .gitignore: two
# independent lists mean a hurried edit fails a check instead of redefining
# what the check expects.
#
#   tests-allowlist.txt  = the PATH policy for tests/ (what may be tracked)
#   disclosure-held.txt  = the CONTENT policy, repo-wide (what may not)
#
# Their intersection must be EMPTY. scripts/check-disclosure-tags.sh fails if
# it is not, so the two lists cannot silently disagree.
#
# WHY THIS LIST EXISTS AT ALL, GIVEN THE HEADER TAGS
# -------------------------------------------------
# The `@disclosure:` header in each file is the primary signal, and the check
# refuses to track anything carrying a (b) or (c) tag. But a header is one
# `sed -i` away from gone, and a check that only reads headers reports CLEAN
# the moment the headers are deleted — indistinguishable from a clean tree.
# This list is the independent witness: every path below must EXIST and must
# still carry a (b)/(c) tag. Delete a header and the check fails loudly.
#
# Source of authority: 2.59a §5.2 + §6.2 + §6.3
# (Graphnosis/data/audit-archive/findings/PII-DISCLOSURE-TESTTREE-2.59a.md).
#
# TO REMOVE A PATH FROM THIS LIST you need an ADOPTION EVENT, not a decision:
#   class (c)  -> a release ships carrying the audit's working-tree fixes.
#   class (b) recall-coverage-* / census / oracle -> `src/recall-coverage.ts`
#              ships AND the resolved secure-sync reports per-graph outcomes.
#   class (b) skills-train-status-label -> `getSkillTrainStatusLabel` ships.
# Until then each file below is a working, runnable reproduction of a defect
# that is live for every user on the shipped build.
#
# Format: one repo-relative path per line. `#` and blanks ignored. No globs.
